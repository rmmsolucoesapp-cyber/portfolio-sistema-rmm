# Sistema RMM

**Sistema desktop de gestão comercial desenvolvido para apoiar as rotinas de uma loja.**

Este repositório é uma apresentação pública do projeto. O código-fonte do sistema principal é mantido em um repositório privado.

## Sobre o projeto

O Sistema RMM nasceu de necessidades reais de operação comercial. A proposta é reunir em um só lugar ferramentas para organizar tarefas do dia a dia e facilitar o acompanhamento da loja.

## Funcionalidades

- Cadastro e consulta de produtos, clientes e fornecedores
- Registro de vendas e apoio à operação de caixa
- Controle de estoque
- Acompanhamento de crediário e parcelas
- Relatórios e rotinas administrativas
- Banco de dados PostgreSQL para uso em rede local
- Licenciamento com período de demonstração e ativação permanente

*As funcionalidades disponíveis podem variar conforme a versão e a configuração do sistema.*

## Tecnologias

- Python
- PyQt6
- PostgreSQL
